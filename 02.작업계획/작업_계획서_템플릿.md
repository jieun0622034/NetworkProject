# 1일차 작업 계획서

* 날짜: 2026-11-01

## 1. 목표

* 프로젝트 계획서의 어느 줄을 해결하나: 5. 일정 - 1일차 (오리엔테이션, Git / 이 계획서)

## 2. 작업 대상

| 대상 | 무엇을 |
| --- | --- |
| Git 및 프로젝트 문서 | 원격 저장소 생성, 로컬 환경 연동 및 프로젝트 계획서 작성 |

## 3. 작업 내용

1. 팀 협업을 위한 Git 원격 저장소(Remote Repository)를 생성한다.
2. 회사의 조직도 및 보안 요구사항을 반영하여 프로젝트 계획서를 작성한다.
3. 작성한 계획서 파일을 커밋(Commit)하고 원격 저장소로 푸시(Push)하여 형상 관리를 시작한다.

## 4. 확인 방법

| 확인할 것 | 방법 | 기대하는 결과 |
| --- | --- | --- |
| Git 저장소 연결 상태 | `git remote -v` 명령어를 통해 원격 저장소 주소 확인 | 등록한 원격 저장소 주소가 정상적으로 출력됨 |
| 푸시 상태 확인 | `git log` 실행 및 원격 저장소 웹 페이지 확인 | 작성한 1일차 계획서 커밋 내역이 원격 저장소에 반영됨 |

## 5. 되돌리는 방법

* `git reset --soft HEAD~1` 명령어로 로컬 수정 사항을 유지하면서 커밋을 취소하고 재설정한다.
