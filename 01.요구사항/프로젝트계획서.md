## 2. 부서와 사용자

| 부서 | 위치 | 인원 | 쓰는 서비스 |
|------|------|------|-------------|
| 영업팀| 본사, 지사 | 9 + 8 | 주문 관리, 파일 서버, 메일 |
| 인사팀 | 본사        | 3     | 급여 자료(파일 서버), 메일 |

| 서버  | 본사 서버실    |  1     | 쇼핑몰 웹 서버, 파일 서버  |

## 3. 연결 요구사항

- 부서 사이: 부서마다 네트워크를 나눈다. 영업팀과 인사팀은 서로 통신할 일이 없다
- 본사와 지사 사이: 지사 영업팀은 본사의 주문 관리와 파일 서버를 쓴다
- 인터넷: 모든 직원이 쓴다
- 밖에서 들어오는 접속: 쇼핑몰은 누구나 접속한다. 그 밖의 서버는 밖에서 보이지 않아야 한다
- 재택 근무: 개발팀 재택 직원은 집에서 본사 내부망에 들어와 쇼핑몰 서버를 관리한다

## 4. 지킬 것과 걱정되는 것

| 지킬 것 | 깨지면 안 되는 것 (기밀성, 무결성, 가용성) | 무엇이 잘못될 수 있나 |
|---------|--------------------------------------------|------------------------|
| 고객 개인정보 | 기밀성        | 밖에서 쇼핑몰 서버 뒤의 데이터에 접근한다      |
| 급여 자료   | 기밀성        | 다른 부서 직원이 인사팀 자료를 연다         |
| 주문 내역   | 무결성        | 본사와 지사 사이에서 주문 내용이 엿보이거나 바뀐다 |
| 쇼핑몰 서비스 | 가용성        | 접속이 몰리거나 공격을 받아 쇼핑몰이 멈춘다     |
| 장비 설정   | 무결성        | 아무나 라우터에 접속해 설정을 바꾼다         |
