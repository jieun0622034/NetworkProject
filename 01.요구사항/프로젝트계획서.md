# 프로젝트 계획서

## 1. 회사 개요

- 회사명: 오존층
- 업종: 온라인 패션 커머스
- 본사 위치 및 인원: 대구 (23명)
- 지사 위치 및 인원: 서울 (8명)
- 외부 공개 서비스: 쇼핑몰 웹 서비스

## 2. 부서 및 사용자 현황

| 부서 | 위치 | 인원 | 주요 이용 서비스 |
|------|------|------|------------------|
| 영업팀 | 본사, 서울지사 | 9명 / 8명 | 주문 관리 시스템, 파일 서버, 그룹웨어/메일 |
| 인사팀 | 본사 | 3명 | 급여·인사 자료(파일 서버), 그룹웨어/메일 |
| 개발팀 | 본사, 재택 | 7명 / 3명 | 쇼핑몰 서버 관리 시스템, 파일 서버 |
| 서버실 | 본사 서버룸 | 1구역 | 쇼핑몰 웹 서버, 내부 통합 파일 서버 |

---

## 3. 네트워크 및 연결 요구사항

- 부서 간 네트워크 분리: VLAN 및 접근 제어 목록(ACL)을 적용하여 부서별 망을 격리하며, 영업팀과 인사팀 간 직접 통신은 차단합니다.
- 본·지사 간 보안 연결: 서울지사 영업팀이 본사의 주문 관리 시스템과 파일 서버에 안전하게 접근할 수 있도록 전용 보안 터널(IPsec VPN)을 구축합니다.
- 인터넷 접속: 전 직원의 업무용 인터넷 접속을 허용하되, 보안 정책을 통과하도록 구성합니다.
- 외부 접속 통제 (DMZ 구성): 쇼핑몰 웹 서버만 외부 사용자에게 공개하고, 파일 서버·주문 서버 등 내부 자원은 외부에서 직접 접근하지 못하도록 차단합니다.
- 재택근무 보안 접속: 개발팀 재택 근무자(3명)는 보안 인증(SSL-VPN)을 통해 내부망에 접속하여 쇼핑몰 서버를 안전하게 관리합니다.

## 4. 보안 자산 및 위협 관리

| 보호 대상 자산 | 보안 목표 (CIA) | 주요 위협 및 위험 시나리오 |
|----------------|------------------|----------------------------|
| 고객 개인정보 | 기밀성 | 외부 공격자가 쇼핑몰 웹 서버를 경유하여 내부 데이터베이스에 무단 접근 |
| 급여 및 인사 자료 | 기밀성 | 타 부서 직원이 인사팀 내부 파일 서버에 인가 없이 접근하여 열람 |
| 주문 및 결제 내역 | 무결성 | 본사와 서울지사 간 데이터 전송 중 제3자의 도청 또는 데이터 위·변조 |
| 쇼핑몰 웹 서비스 | 가용성 | 접속 트래픽 폭주 또는 DDoS 공격으로 인해 쇼핑몰 서비스가 마비 |
| 네트워크 장비 설정 | 무결성 | 비인가자의 라우터·스위치 접근으로 인한 네트워크 설정 변경 및 마비 |
